# Game Reviews

A game discovery website: browse a selection of games, view details for each one, and jump to play or download. Built as a front-end practice project with a focus on layout and UI polish.

![Screenshot](screenshot.png)

**Live demo:** https://moazkandeel.github.io/game-reviewos/

## Features

- Games listing with artwork
- Per-game details pages
- Responsive layout

## Tech stack

HTML5, CSS3, JavaScript, Bootstrap

## Run locally

Open `index.html` in a browser, or visit the live demo above.
